プライバシーポリシー（clasp project）

株式会社revolution（以下「当社」）が社内で使う業務用ツール「clasp project」での、Google のデータの扱いを定めます。

1. 使う人

当社の担当者だけが、自分の Google アカウントで使います。一般の方は使えません。

2. 使う Google のデータ

担当者自身の Google スプレッドシートと Apps Script のプロジェクトです。

3. 使う目的

当社の業務（スプレッドシートの点検・記録、Apps Script の管理と実行）のためだけに使います。

4. 第三者への提供

Google のデータを第三者に売ったり、渡したりしません。広告にも使いません。

5. 保管

データは担当者の Google アカウントの中に残ります。このツールが外部のサーバーに写しを保管することはありません。

6. 許可の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも許可を取り消せます。

Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
